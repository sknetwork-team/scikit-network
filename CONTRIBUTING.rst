============
Contributing
============

Contributions are welcome, and they are greatly appreciated! 

You can contribute in many ways:

Report Bugs
~~~~~~~~~~~

Report bugs as issues on https://github.com/sknetwork-team/scikit-network/

If you are reporting a bug, please include:

* Your operating system name and version.
* Any details about your local setup that might be helpful in troubleshooting.
* Detailed steps to reproduce the bug.

Fix Bugs
~~~~~~~~

Look through the issues on https://github.com/sknetwork-team/scikit-network/ 


Submit Feedback
~~~~~~~~~~~~~~~

Launch a discussion on https://github.com/sknetwork-team/scikit-network/


Pull Request
~~~~~~~~~~~~

A guide for writing code is available on the Wiki_.
